# Lewisham Maroon Plaques Missing From OpenPlaques

Source: `Maroon Plaque Location and Text List 2025.docx`

This list contains Lewisham maroon plaque records from the 2025 source document that do not appear to have an exact matching OpenPlaques point in the London OpenPlaques dump checked on 2026-04-18.

An exact match means the OpenPlaques point appears to describe the same plaque at the same location. Related records about the same subject at a different location are noted separately.

## Missing exact matches

- Approximate coordinate from postcode: 51.444622, -0.021058
- Plaque text: In memory of the young people who died, New Cross fire, 18 January 1981. {On rectangular plaque below are listed 14 names. See Subjects commemorated.}

- OpenPlaques search note: OpenPlaques record 6304 exists for the New Cross Fire at the fire site, but not for this Civic Suite maroon plaque.
